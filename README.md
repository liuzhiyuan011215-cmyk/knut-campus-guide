## 2. 로컬 실행 방법

별도의 Node.js나 Python 서버 설치 없이 `index.html` 파일을 더블클릭하면 브라우저에서 즉시 실행됩니다.

---

## 3. 수정 방법 (선택)

`index.html`은 빌드 결과물입니다. 디자인·문구를 고치려면 `src/template.html`, 데이터를 고치려면 `src/data.json`을 수정한 뒤 다시 만듭니다.

```bash
python3 src/build.py
```

데이터와 네이버 플레이스 실사진(`assets/`)이 `index.html` 하나에 들어가므로, GitHub에는 `index.html`만 올려도 됩니다. (원본 사진 폴더 `assets/`는 용량 때문에 저장소에 넣지 않았고, 배포된 `index.html`에 이미 들어 있습니다. 그래서 `build.py`를 다시 실행하려면 사진 폴더가 따로 필요합니다.)
